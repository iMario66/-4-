#### Проект функций:
* **-scanf_data** — получает от пользователя значения и сохраняет их в переменные.
* **-validate** — проверяет, корректные ли значения ввел пользователь.
* **-basic_tariff** — рассчитывает базовый тариф.
* **-night_coeff_foo** — рассчитывает ночной коэффициент.
* **-total_foo** — рассчитывает итоговую стоимость.
* **-get_total** — определяет по полученным значениям исход программы и что конкретно надо вывести в консоль.
* **-print_all_data** — выводит исход программы и в зависимости от этого принимает решение, выводить рассчитанные данные или нет (если да - выводит).
* **-main** — выполняет вызов всех выше перечисленных функций, сохраняя посчитанные ими значения и выводя с помощью функций эти значения на экран.

#### Таблица контрактов: 
* **-scanf_data:** 
  * **Назначение:** получает от пользователя значения через scanf, а затем, используя указатели, сохраняет их в переменные, которые находятся в функции main.
  * **Параметры:** double* dist, int* dur, int* hour, int* pass, int* lugg, double* sur, double* payment - все переменные, которым нужно присвоить значения, полученные от пользователя. Указатели необходимы для того чтобы изменения сохранились в main.
  * **Допустимые значения:** любые данные, если они принадлежат указанному типу. В любом случае в след. программе они будут проверяться.
  * **Возвращаемый результат:** ничего, функция void.
  * **Побочные эффекты:** записывает в переменные функции main значения, введенные пользователем.
* **-validate:** 
  * **Назначение:** проверяет, корректные ли значения ввел пользователь (например, не являются ли такие переменные, как distance (пройденный путь), passengers(количество пассажиров) и т.д. отрицательными). В зависимости от правильности данных флагу (first_flag) присваивается конкретное значение, на основании которого программа делает след. шаги.
  * **Параметры:** double dist, int dur, int hour, int pass, int lugg, double sur, double payment - как и в ф-ии scanf_data, все переменные, которым нужно присвоить значения, полученные от пользователя.
  * **Допустимые значения:** любые данные, если они принадлежат указанному типу. 
  * **Возвращаемый результат:** целое число 1 или 0 (1 - если проверка на корректность данных успешно пройдена, иначе 0)
  * **Побочные эффекты:** нет
* **-basic_tariff:** 
  * **Назначение:** рассчитывает базовый тариф по формуле `3.5 + dist * 0.9 + dur * 0.12`
  * **Параметры:** double dist, int dur - пройденная дистанция и затраченное время.
  * **Допустимые значения:** неотрицательные дистанция и время, принадлежащие double и int соответственно.
  * **Возвращаемый результат:** дробное число double (базовый тариф за поездку).
  * **Побочные эффекты:** нет.
* **-night_coeff_foo:** 
  * **Назначение:** рассчитывает ночной коэффициент по алгоритму `(hour < 6 || hour >= 23) ? 1.2 : 1.0` (если время от 23 до 5 включительно - возвращаем 1.2 коэфф, иначе 1.0).
  * **Параметры:** int hour - время начала поездки (в часах)
  * **Допустимые значения:** hour должен быть целым числом, от 0 до 23 включительно.
  * **Возвращаемый результат:** дробное число double (ночной коэффициент).
  * **Побочные эффекты:** нет.
* **-total_foo:** 
  * **Назначение:** рассчитывает итоговую стоимость по формуле `base * n_coeff * sur + lugg_fee`
  * **Параметры:** double base, double n_coeff, double sur, double lugg_fee - базовый тариф, ночной коэффициент и стоимость за багаж (рассч. по формуле luggage * 1.5)
  * **Допустимые значения:** все числа дробные, неотрицательные.
  * **Возвращаемый результат:** дробное число double (итоговая стоимость поездки).
  * **Побочные эффекты:** нет.
* **-get_total:** 
  * **Назначение:** определяет по полученным значениям (кол-во пассажиров, итоговая стоимость, повышенный коэффициент) исход программы и что конкретно надо вывести в консоль (DENIED_CAPACITY / PAYMENT_REQUIRED / HIGH_SURGE / COMPLETE)
  * **Параметры:** int pass, double payment, double total, double surge.
  * **Допустимые значения:** положительное целое число пассажиров, дробное неотрицательно число суммы (которую отдал пассажир), дробная неотрицательная итоговая стоимость, дробный повышенный коэффициент (не меньше 1.0).
  * **Возвращаемый результат:** 0/1/2/3 (0 - если пассажиров больше 4, 1 - если оплата меньше итоговой стоимости, 2 - если повышенный коэффициент больше 1.5, иначе 3).
  * **Побочные эффекты:** нет.
* **-print_all_data:** 
  * **Назначение:** выводит исход программы (DENIED_CAPACITY / PAYMENT_REQUIRED / HIGH_SURGE / COMPLETE) и в зависимости от этого принимает решение, выводить рассчитанные данные или нет (при DENIED_CAPACITY - не выводит, иначе выводит).
  * **Параметры:** double total, double per_pers, double change, int flag - итоговая стоимость поездки, стоимость на одного пассажира, сдача, флаг (полученный от функции get_total)
  * **Допустимые значения:** дробная неотрицательная итоговая стоимость, дробная неотрицательная стоимость поездки на каждого пассажира, дробная сдача, флаг от 0 до 3.
  * **Возвращаемый результат:** ничего, функция void.
  * **Побочные эффекты:** выводит в зависимости от флага исход программы (DENIED_CAPACITY - если флаг = 0, PAYMENT_REQUIRED - если флаг = 1,HIGH_SURGE - если флаг = 2, COMPLETE - если флаг = 3). Если флаг != 0, выводит также total, per_person, change.
* **-main:** 
  * **Назначение:** выполняет вызов всех выше перечисленных функций, сохраняя посчитанные ими значения и выводя с помощью функций эти значения на экран
  * **Параметры:** нет.
  * **Допустимые значения:** их нет.
  * **Возвращаемый результат:** 1 - если программа завершена с ошибкой, иначе 0.
  * **Побочные эффекты:** через функции принимает от пользователя значения, присваивает их в конкретные переменные, проверяет их на корректность, рассчитывает базовый тариф base, ночной коэфф. night_coeff, стоимость багажа luggage_fee, итоговую стоимость total, стоимость на человека per_person, стоимость сдачи change, в зависимости от флага second_flag выводит исход программы и (если это надо) рассчитанные значения.
